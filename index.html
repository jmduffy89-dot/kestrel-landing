Why not just use ChatGPT?

A fair question — here's the honest, structural answer, not just "because AI."

Data source

Every chat session starts blind.

A chat tool searching Find a Tender right now only sees what's there right now — it has no memory of what existed yesterday, so it can't notice when something quietly changes or disappears. Kestrel checks the government's real data feed daily against everything we've ever seen, specifically to catch what's changed.

Methodology

Chat memory is a loose note. Ours is a structured record.

A chat tool's memory only stores what you happen to tell it, when you think to mention it — there's no way to point it at a 50-page tender document and have it reliably extract and remember the exact word limit or evaluation weighting on its own. Kestrel builds a real, structured record automatically — every confirmed fact timestamped and sourced, and every tender's actual rules extracted directly from the document itself.
